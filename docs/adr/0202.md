# Ejercicio 2 — Simulación de iteración ágil

## Iteración 1 — Funcionalidades básicas

### Tarjeta CRC: `Artículo`

| Clase Artículo | |
|---|---|
| Responsabilidades | Colaboradores |
| Conocer su nombre | - |
| Conocer su precio unitario | - |

### Tarjeta CRC: `Carrito`

| Clase Carrito | |
|---|---|
| Responsabilidades | Colaboradores |
| Añadir un artículo | `Artículo` |
| Calcular el total | `Artículo` |
| Conocer cuántos artículos contiene | `Artículo` |

### Casos de prueba

Se comprueba que un carrito recién creado, sin artículos, tenga un total de 0.

Después se añaden dos artículos, por ejemplo, uno de 10 € y otro de 15 €. Se comprueba que el total del carrito sea 25 € y que informe de que contiene 2 artículos.

## Iteración 2 — Funcionalidades tras la revisión con el cliente

### Tarjeta CRC actualizada: `Artículo`

### Tarjeta CRC actualizada: `Carrito`

| Clase Carrito | |
|---|---|
| Responsabilidades | Colaboradores |
| Añadir un artículo | `Artículo` |
| Eliminar un artículo por nombre | `Artículo` |
| Calcular el total | `Artículo` |
| Calcular el total aplicando un descuento porcentual | `Artículo` |
| Conocer cuántos artículos contiene | - |

### Nuevos casos de prueba

Si el carrito contiene un artículo llamado «Teclado» y se elimina por ese nombre, se comprueba que deja de estar en el carrito, que la cantidad disminuye en uno y que el total se recalcula sin su precio.

Si se intenta eliminar un artículo cuyo nombre no existe en el carrito, se comprueba que el contenido, la cantidad y el total permanecen sin cambios, y que no se elimina otro artículo por error.

Al aplicar un descuento del 10 % a un carrito cuyo total sea 100 €, se comprueba que el total final sea 90 €. Si se aplica un descuento del 0 %, el total debe ser el mismo que antes de aplicar el descuento.
