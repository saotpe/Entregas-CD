# Ejercicio 1 — Diseño con tarjetas CRC

## 1. Tarjetas CRC
#### Tarjeta CRC: `Libro`

| Clase Libro | |
|---|---|
| Responsabilidades | Colaboradores |
| Conocer su título, autor e ISBN | - |
| Conocer el número de ejemplares disponibles | - |
| Prestar un ejemplar (si hay disponibles) | `Préstamo` |
| Recibir la devolución de un ejemplar | `Préstamo` |

#### Tarjeta CRC: `Socio`

| Clase Socio | |
|---|---|
| Responsabilidades | Colaboradores |
| Conocer su nombre, número de socio y fecha de alta | - |
| Solicitar el préstamo de un libro | `Libro`,`Préstamo` |
| Devolver un libro prestado | `Préstamo` |

#### Tarjeta CRC: Préstamo

| Clase Préstamo | |
| Responsabilidades | Colaboradores |
|---|---|
| Conocer qué libro y qué socio están implicados | `Libro`, `Socio` |
| Conocer la fecha de inicio del préstamo | - |
| Registrar la devolución del préstamo | `Libro` |

## 2. Intento de préstamo de un ejemplar

Según la tarjeta CRC, `Libro` es responsable de prestar un ejemplar si hay disponibilidad y colabora con `Préstamo`. Antes de prestarlo, comprueba que el número de ejemplares disponibles sea mayor que cero.

- **Si hay ejemplares disponibles**, `Libro` reduce en uno esa cantidad y se registra el préstamo mediante `Préstamo`, que relaciona el libro con el socio y conoce la fecha de inicio.
- **Si no hay ejemplares disponibles**, el préstamo no se realiza: no se registra un nuevo préstamo y el objeto `Libro` permanece igual, con el mismo número de ejemplares.

Cuando se devuelve un ejemplar, `Libro` recibe la devolución a través de `Préstamo` y aumenta en uno el número de ejemplares disponibles. `Préstamo` registra que se ha devuelto.

## 3. Flujo de gestión

1. **Se da de alta un libro con 3 ejemplares.**  
   `Libro` guarda sus datos (título, autor e ISBN) y establece en 3 el número de ejemplares disponibles.

2. **Se dan de alta dos socios.**  
   Se crean dos objetos `Socio`, cada uno con su nombre, número de socio y fecha de alta.

3. **El primer socio toma prestado el libro.**  
   `Socio` solicita el préstamo. `Préstamo` relaciona al socio con el libro y `Libro` comprueba que hay ejemplares. La operación tiene éxito: quedan 2 ejemplares disponibles.

4. **El segundo socio intenta tomar el mismo libro.**  
   `Socio` solicita otro préstamo. `Libro` comprueba de nuevo la disponibilidad; como quedan 2 ejemplares, tiene éxito y se crea otro `Préstamo`. Queda 1 ejemplar disponible.

5. **El primer socio devuelve el libro.**  
   El `Préstamo` correspondiente registra la devolución y `Libro` actualiza la disponibilidad. Quedan 2 ejemplares disponibles.

6. **El segundo socio vuelve a intentar tomar el libro.**  
   `Libro` comprueba que quedan ejemplares, así que el intento tiene éxito. Se crea un nuevo `Préstamo` y quedan 1 ejemplar disponible.
